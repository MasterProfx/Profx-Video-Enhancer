# Profx Video Enhancer — راهنمای فارسی

این مخزن یک Fork از پروژهٔ متن‌باز [Veyra-NRVideo](https://github.com/Likely7/Veyra-NRVideo) است. کد موتور اصلی از پروژهٔ upstream به ارث رسیده؛ این Fork فعلاً مستندات فارسی و معرفی اختصاصی Profx را اضافه می‌کند و هنوز تغییرات اختصاصی در موتور پردازش یا فایل اجرایی ندارد.

## معرفی
Veyra برنامه‌ای برای پردازش زندهٔ تصویر و ویدئو با GPU در Windows است. قابلیت‌های پروژهٔ اصلی، بسته به نسخه و سخت‌افزار، شامل Super Resolution، Denoising / Noise Reduction، HDR، Frame Generation، Capture، Streaming و Export می‌شود.

پشتیبانی هر قابلیت به GPU، درایور، مدل AI و Runtime موردنیاز وابسته است. وجود گزینه در رابط کاربری به معنی سازگاری با همهٔ سیستم‌ها نیست.

## دریافت نسخهٔ آماده
برای دریافت فایل اجرایی از [صفحهٔ رسمی Releases](https://github.com/Likely7/Veyra-NRVideo/releases) استفاده کنید. این Fork به‌تنهایی فایل اجرایی جدیدی تولید نمی‌کند.

## نصب کلی
1. بستهٔ متناسب با GPU و نسخهٔ موردنظر را از Releases دریافت کنید.
2. فایل ZIP را در پوشه‌ای جداگانه استخراج کنید.
3. دستورالعمل همان Release را برای اجرای برنامه دنبال کنید.
4. ابتدا با تنظیمات سبک و یک افکت فعال تست کنید.
5. قبل از ارتقا از تنظیمات و داده‌های شخصی پشتیبان بگیرید.

فایل‌های NVIDIA و AMD یا Runtime نسخه‌های مختلف را با هم ترکیب نکنید.

## پایش و ایمنی GPU
پردازش AI می‌تواند مصرف GPU، VRAM، توان و سرعت فن را افزایش دهد. استفادهٔ بالا به‌تنهایی نشانهٔ خرابی نیست؛ دما و پایداری سیستم مهم‌ترند. راهنمای کامل: [ایمنی GPU به فارسی](docs/PROFX_GPU_SAFETY_FA.md).
