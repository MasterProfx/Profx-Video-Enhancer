# راهنمای ایمنی GPU برای Profx Video Enhancer

این راهنما جایگزین محدودیت‌های رسمی سازندهٔ GPU نیست. دمای مجاز به مدل کارت، خنک‌کننده، کیس و شرایط محیط بستگی دارد؛ یک عدد ثابت برای همهٔ کارت‌ها معتبر نیست.

## هنگام پردازش چه انتظاری داشته باشیم؟
فعال‌سازی Super Resolution، Denoising، HDR یا Frame Generation ممکن است GPU Usage، مصرف توان، VRAM و سرعت فن را افزایش دهد. استفادهٔ ۱۰۰٪ GPU به‌تنهایی نشانهٔ خرابی نیست.

## چک‌لیست
1. از درایور پایدار و رسمی استفاده کنید.
2. پیش از تست، دمای GPU و Hot Spot را ثبت کنید.
3. افکت‌ها را یکی‌یکی فعال کنید و هر بار نتیجه را بسنجید.
4. دما، توان، VRAM و پایداری را با ابزار معتبر پایش کنید.
5. اگر از محدودهٔ مجاز سازنده عبور کردید، یا Artifact، Crash، Driver Reset یا ناپایداری دیدید، پردازش را متوقف کنید.
6. در صورت کمبود VRAM، وضوح، FPS یا تعداد افکت‌ها را کاهش دهید.

## کاهش بار
- وضوح یا نرخ فریم را پایین بیاورید.
- تعداد لایه‌ها و افکت‌های فعال را کم کنید.
- مدل سبک‌تر انتخاب کنید.
- برنامه‌های سنگین دیگر GPU را ببندید.
- برای جبران کمبود کارایی، اورکلاک یا افزایش ولتاژ ناپایدار انجام ندهید.

## محدودیت فعلی Fork
این Fork در حال حاضر فقط مستندات فارسی را اضافه می‌کند. قابلیت اختصاصی GPU Usage Limiter، FPS Limiter، پایش دما یا توقف خودکار در آن پیاده‌سازی و آزمایش نشده است؛ بنابراین نباید فرض کرد برنامه چنین محافظت‌هایی انجام می‌دهد.
