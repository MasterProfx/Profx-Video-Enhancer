## توضیح

گزارش‌های قدیمی برای حفظ سابقهٔ فنی نگهداری شده‌اند. تاریخ و وضعیت نوشته‌شده در هر گزارش مربوط به زمان ثبت همان گزارش است و لزوماً وضعیت فعلی پروژه را نشان نمی‌دهد.

نام فایل‌ها، شناسه‌های فنی، مسیرهای کد، فرمان‌ها، نام APIها و اصطلاحات استاندارد برنامه‌نویسی برای جلوگیری از اختلال در ساخت و ارجاع فنی، بدون ترجمه باقی می‌مانند.
